# 🎮 AirRunner – AI-Powered Hand Gesture Gaming

AirRunner is a touchless gaming project that allows players to control an interactive game using **real-time hand gestures** captured through a webcam.

Instead of using a keyboard or controller, AirRunner uses **computer vision and hand-tracking technology** to understand the player's hand movements and convert them into game actions.

## 🚀 Project Overview

The main idea behind AirRunner is simple:

**Move your hand → AirRunner recognizes the gesture → The game responds.**

For example:

| Hand Gesture                           | Game Action |
| -------------------------------------- | ----------- |
| Move hand ↑                            | Jump        |
| Move hand ↓                            | Slide       |
| Move hand ←                            | Move Left   |
| Move hand →                            | Move Right  |
| Bring thumb + index finger together 🤏 | Roll        |

The concept is inspired by gesture-based controls in endless runner games such as Temple Run, while replacing traditional keyboard or controller input with natural hand movements.

## ✨ Features

*  Real-time webcam-based hand tracking
*  Touchless game control
*  Gesture-based player movement
*  Jump control
*  Slide control
*  Left and right movement
*  Pinch gesture for rolling
*  Interactive endless-runner style gameplay
*  Score and gameplay tracking
*  Real-time gesture response

## 🎯 Project Objective

The objective of AirRunner is to create a **touchless and interactive gaming experience** where players can control a game using natural hand movements.

The project demonstrates the practical use of:

* Computer Vision
* Hand Gesture Recognition
* Artificial Intelligence
* Real-Time Interaction
* Web Technologies

## 💡 Why AirRunner?

Traditional games commonly rely on keyboards, controllers, or touchscreens.

AirRunner explores a more natural interaction method by allowing users to **control gameplay through hand movements captured by a webcam**.

It combines computer vision and interactive game development to create an engaging and immersive gaming experience.
